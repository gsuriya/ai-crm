# Make Stripe Checkout Look Better

## Option 1: Customize Stripe Branding (Quick Fix)

Go to your Stripe Dashboard and customize the checkout appearance:

1. Go to: https://dashboard.stripe.com/settings/branding
2. Upload your logo (the Cheddar logo)
3. Set brand color to: `#000000` (black)
4. Set accent color to: `#6366f1` (indigo)
5. This will make the checkout match your app's theme

## Option 2: Use Embedded Checkout (Better UX)

Instead of redirecting to Stripe's page, embed the checkout directly in your app.
This keeps users on your site and looks way cleaner.
